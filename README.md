# Desktop helpers

Small Mac and Windows apps that let a website do something a browser can't do by itself, on your own computer.
Each helper has its own folder with install steps, privacy details and licences. The installers are on the
[releases page](https://github.com/karwasandesh/inthetab-helper/releases).

| Helper | What it does | Docs |
|---|---|---|
| **InTheTab Helper** | Saves YouTube videos as MP4 or MP3 for the [InTheTab YouTube downloader](https://inthetab.com/youtube-downloader/). | [inthetab-helper/](inthetab-helper/#readme) |
| **Maya WhatsApp Helper** | Adds products from Maya Studio to The Maya Store's WhatsApp Business catalog. | [maya-whatsapp-helper/](maya-whatsapp-helper/#readme) |

Questions or problems: [open an issue](https://github.com/karwasandesh/inthetab-helper/issues).
